# Paillier medical numeric data experiment

پیاده‌سازی پژوهشی رمزگذاری دو ویژگی عددی از رکوردهای کاملاً فرضی، بازیابی آن‌ها و محاسبه مجموع و میانگین با Paillier. این مخزن سامانه آماده استقرار بالینی نیست.

## نصب و اجرا

Python 3.12 در اجرای مرجع استفاده شده است. در پوشه پروژه اجرا کنید:

```bash
python -m venv .venv
```

فعال‌سازی در Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

فعال‌سازی در Linux/macOS:

```bash
source .venv/bin/activate
```

سپس:

```bash
python -m pip install -r requirements.txt
python src/experiment.py generate --count 5000 --seed 20261005
python src/demo.py --count 1000 --bits 2048
python src/experiment.py benchmark --sizes 100 1000 5000 --bits 1024 2048 --repeats 3
```

بازسازی نمودارها از CSV موجود، بدون تکرار آزمایش:

```bash
python src/experiment.py charts
```

## محتوا

- `src/experiment.py`: تولید داده، آزمایش زمان‌سنجی، ذخیره نتایج و تولید ۱۲ نمودار PNG/PDF.
- `src/demo.py`: جریان کامل SQLite، رمزگذاری، رمزگشایی و جمع همومورفیک.
- `data/`: داده‌های فرضی و روش تولید آن‌ها.
- `results/`: خروجی خام، میانگین و انحراف معیار و مشخصات محیط اجرای مرجع.
- `figures/`: نمودارها؛ میله خطا در نمودارهای زمانی، انحراف معیار سه تکرار است.
- `docs/`: فصل‌های اصلاح‌شده و راهنمای انتشار.

## روش و محدودیت‌ها

اعداد با Decimal به عدد صحیح در مقیاس ۱۰۰ تبدیل می‌شوند. این تبدیل برای داده‌های دو رقمی موجود دقیق است؛ برای داده‌هایی با اعشار بیشتر محدودیت دارد. نمای رمزگذاری در این نسخه صفر است و مقیاس ۱۰۰ باید هنگام بازیابی رعایت شود. این نسخه اصلاح‌شده با کد اعشاری اولیه تفاوت دارد؛ نتایج مربوط به همین نسخه است.

دو اندازه کلید ۱۰۲۴ و ۲۰۴۸ فقط برای مقایسه عملکرد آزمایش شده‌اند؛ ۱۰۲۴ توصیه امنیتی نیست و این مخزن ادعای کفایت ۲۰۴۸ برای استقرار واقعی ندارد. هر ترکیب تعداد رکورد و اندازه کلید سه بار با کلید جدید اجرا شده است. زمان‌های رمزنگاری مستقل از زمان خواندن و نوشتن SQLite ثبت می‌شوند. نتیجه تجمیعی شامل جمع دو ستون و رمزگشایی دو مجموع است. سرعت رمزگشایی همه رکوردها با همین کار مقایسه می‌شود، نه با رمزگذاری اولیه.

اجرای مرجع در محیط Linux میزبانی‌شده انجام شده؛ اطلاعات دقیق در `results/environment.json` است. زمان‌های رایانه شما ممکن است متفاوت باشند. نمونه داده ثابت است، ولی کلیدها و متن‌های رمز تصادفی‌اند. نتایج قبلی ۱۰۰ رکوردی پایان‌نامه با این اندازه‌گیری‌های جدید جایگزین شده‌اند.

کلید خصوصی فقط در حافظه تولید و استفاده می‌شود؛ هیچ کلید خصوصی در مخزن نیست. فایل‌های local_run فقط محلی‌اند. این نسخه رمزگشایی با کلید پایدار در اجرای جداگانه، کنترل دسترسی، مدیریت کلید سازمانی یا حفاظت از سایر ستون‌ها را پیاده‌سازی نمی‌کند. نام‌ها ساختگی‌اند؛ در داده واقعی، شناسه‌ها و سایر ویژگی‌های سلامت نیز نیازمند حفاظت هستند.

نتایج تجربی ضمانت امنیت رمزنگاری یا اعتبار بالینی محسوب نمی‌شوند. این آزمایش فقط یک پیاده‌سازی را ارزیابی می‌کند و برتری تجربی بر روش‌های دیگری که اجرا نشده‌اند را اثبات نمی‌کند.
